# Задание 1. Анализ и планирование

### 1. Описание функциональности монолитного приложения

Домены проекта:

**1. Домен сенсоров (Sensor Domain)**

Ответственность: Управление данными сенсоров умного дома

Сущности:

Sensor - основная сущность сенсора
SensorType - тип сенсора (значение-объект)
Value Objects:

SensorCreate - данные для создания сенсора
SensorUpdate - данные для обновления сенсора
Сервисы домена:

Логика валидации сенсоров
Правила обновления статусов сенсоров

**2. Домен температурных данных (Temperature Domain)**

Ответственность: Получение и обработка температурных данных

Value Objects:

TemperatureResponse - ответ от внешнего API температуры
Сервисы домена:

TemperatureService - сервис для взаимодействия с внешним API температуры
Логика преобразования температурных данных

**3. Инфраструктурный домен (Infrastructure Domain)**

Ответственность: Техническая реализация доступа к данным и внешним сервисам

Реализации репозиториев:

DB - работа с PostgreSQL
Миграции базы данных (init.sql)
Внешние сервисы:

HTTP клиенты для внешних API
Конфигурация подключений

**4. Прикладной домен (Application Domain)**

Ответственность: Координация работы доменов и предоставление API

Обработчики:

SensorHandler - обработка HTTP запросов для сенсоров
Сервисы приложения:

Оркестрация бизнес-процессов
Валидация входящих запросов
